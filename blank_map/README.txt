백지도 인접 지역 연결

지도 패널은 지역 제목·동 개수 → ‘구만 표시’ → 접이식 ‘지역 연결’ → 지도 순서로 구성한다.
설정은 기본 접힘이며 연결·폰트 변경 후에도 사용자가 열어 둔 상태를 유지한다.
접힌 요약에는 선택 지역 수를 표시한다. 동 개수는 지역 제목 옆에 두고 좁은 화면에서는 자연스럽게 줄바꿈한다.
연결 지역 제목은 첫 지역과 추가 지역 수로 줄인다. 전체 지역 목록·개별 제외는 지역 연결 안에 둔다.
로딩·실패·재시도는 접힌 영역 밖에서 표시한다. 완료 알림은 화면 읽기 도구에만 전달한다.

메인 타이틀 아래 “폰트 선택”에서 다른 페이지와 같은 11개 글씨체를 선택한다. 페이지 전체에 적용되는 설정이므로 지도 패널 밖에 둔다.
selectedFont 저장 키를 공유해 선택을 복원하며, 페이지·단독/연결 지도·구만 표시·확대 보기·PNG/SVG에 적용한다.
글씨체는 이미지 SVG 안에 내장해 다운로드 파일에서도 유지한다. 필요한 글씨체와 단독 지도 자료만 지연 로딩한다.
단독 행정동 지도는 원본 SVG의 경계·글자 위치를 보존한다. 단독 법정동 지도는 연결 지도와 같은 정리된 표시용 경계를 쓴다. file://에서도 fetch 없이 일반 JS로 불러온다.
Google Fonts의 Noto 2종은 지도/페이지에 쓰는 문자로 서브셋한 TTF, 나눔고딕은 원본 TTF이며 data/fonts의 OFL을 따른다. 나머지 8종은 기존 공용 fonts의 WOFF2다.
자료 재생성: python3 blank_map/tools/build_font_assets.py /path/to/google-font-ttfs (sans.ttf, nanum.ttf, serif.ttf).
data/font-maps는 원본 SVG 2종을 gzip으로 압축하며 브라우저의 DecompressionStream으로 복원한다.

사용: 지역 선택 → 연결할 지역 선택 → 연결.
현재 지도에 포함된 지역 중 하나와 경계를 맞댄 지역을 추가할 수 있다.
지역 옆 ×로 제외할 수 있다. 제외 후 지역들이 떨어지면 해당 ×는 비활성화된다.
연결 해제는 처음 선택한 지역으로 돌아간다. 왼쪽 지역 목록은 새 단독 지도를 연다.
연결 상태 URL 예: blankMap.html#23+22 (강남구 + 서초구).
행정동/법정동, 이름 있음/없음 4종 미리보기 및 PNG/SVG 다운로드를 지원한다.
“구만 표시” 체크 시 행정동 좌표의 공유 경계를 제거한 구·시 외곽선 2종(이름 있음/없음)을 표시한다.
연결한 지역 사이의 경계는 유지하고, 구가 없는 시는 시 외곽선을 표시한다.
외곽선은 기존 검증된 2026-10-01 행정동 좌표에서 파생하며, 새 경계 자료를 가져오거나 갱신하지 않는다.
구 이름은 가장 큰 육지 윤곽의 면적 중심에 배치한다. 중심이 구 밖이나 구멍·경계에 가까우면 글자가 들어갈 여유가 있는 중앙 근처 내부점으로 보정한다.
떨어진 섬 때문에 이름이 바다로 밀리지 않으며, 확대 보기와 PNG/SVG 다운로드에도 같은 위치를 사용한다.
구 이름은 카드·전체 보기에서 지도가 축소되는 비율에 반비례해 크게 그려 화면에서 약 14px 이상을 유지한다.
화면 크기가 바뀌면 자동 보정하며 원본 크기 보기와 다운로드는 기존 글씨 크기를 유지한다.
구·시 외곽선은 “구만 표시” 여부와 관계없이 전체 이미지 크기가 커지는 비율만큼 두껍게 그리며, PNG/SVG에도 적용한다.
구·시 외곽선은 카드·전체 보기에서 화면 최소 1.2px이 되도록 추가 보정한다. 내부 행정동·법정동 경계는 원본·축소 보기·다운로드 모두 기존 1.6 굵기를 유지한다.
구·시 외곽선은 각 지도의 좌표에서 추출한다. 행정동 외곽선을 법정동에 대입하지 않는다.
법정동은 원자료의 독립 단순화로 생긴 동 사이 틈·겹침을 표시용 복사본에서 정리한다. coverage_clean(gap_width=40m, snapping_distance=최대20m)을 적용하며 작은 동이 사라지면 스냅 허용치를 낮춘다. 원본 legal.features는 보존한다.
정리한 경계의 합집합을 한 번만 그려 이중선과 잔가지를 줄이고, 같은 도형의 외부 둘레에서 굵은 구·시 외곽선을 만든다. 내부 구멍은 얇은 선으로만 표시한다. 표시용 이름 사각형도 해당 동 안에 있는지 검사한다.
표시 좌표가 허용치 내에서 달라지거나 좁은 실제 틈이 메워질 수 있다. 이는 원자료의 표시 보정이며 공식 경계 갱신이나 새로운 지리적 전수 검증을 의미하지 않는다.
검증: data/legal-outline-validation.json. 재생성: python3 blank_map/tools/build_legal_outlines.py (Shapely >=2.2 / GEOS >=3.14 필요).

연결 지도는 data/connections/{id}.js을 일반 script 태그로 필요할 때 불러온다. 로컬 파일의 JSON fetch에 의존하지 않는다.
HTML 파일을 직접 열거나 정적 HTTP 서버/GitHub Pages 등으로 서비스할 수 있다. 새 API나 외부 지도 SDK는 필요 없다.
SVG는 고정된 공통 투영 좌표를 사용하며, 이름 있는 지도와 없는 지도는 경로를 공유한다.
연결 지도는 첫 지역의 단독 좌표 지도 축척을 유지하고, 추가한 지역 범위만큼 이미지 가로·세로 크기를 늘린다.
카드는 전체 미리보기를 표시하고, 확대 창은 연결 지도를 원본 크기로 열어 스크롤할 수 있다. 전체 보기/원본 크기로 전환 가능하다.
PNG는 브라우저에서 SVG의 2배 해상도로 생성한다. 최대 변 8192px/약 2400만 화소를 넘으면 자동 축소하지 않고 SVG 다운로드를 안내한다.

좌표/인접 판정의 기준일과 제약: data/connection-validation.json.
각 지역의 참고 지도 URL: data/connections/{id}.js의 referenceMap.
행정동: 2026-10-01, 법정동: 2023-07-29 좌표에 기존 제작 입력의 최신 명칭 반영.
법정동 원본의 미세 틈/겹침은 원자료에 보존하며, 실제 표시는 별도의 정리된 경계를 사용한다. 인접 판정은 기존 원자료와 그래프를 유지한다.
기존 단독 지도 파일 자체는 2026-09-30 참고 그림 기반 결과를 보존한다. 화면의 법정동 지도와 다운로드는 정리된 표시용 좌표에서 생성한다.

재생성 (apt-utils에서 실행, numpy/scipy/Pillow/Shapely 필요):
python3 blank_map/tools/build_connections.py ../전체지역_백지도/제작자료
입력 파일·기준일을 검토한 후 재생성한다. 실행 시 경계를 자동 갱신하지 않는다.

검사 (apt-utils에서 실행):
node blank_map/tests/connections.test.js
node blank_map/tests/app.test.js
node blank_map/tests/fonts.test.js
python3 blank_map/tests/legal_display_test.py

인접 그래프, 연결 상태/실패/빠른 전환을 검사한다.
