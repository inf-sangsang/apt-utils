백지도 인접 지역 연결

사용: 지역 선택 → 연결할 지역 선택 → 연결.
현재 지도에 포함된 지역 중 하나와 경계를 맞댄 지역을 추가할 수 있다.
지역 옆 ×로 제외할 수 있다. 제외 후 지역들이 떨어지면 해당 ×는 비활성화된다.
연결 해제는 처음 선택한 지역으로 돌아간다. 왼쪽 지역 목록은 새 단독 지도를 연다.
연결 상태 URL 예: blankMap.html#23+22 (강남구 + 서초구).
행정동/법정동, 이름 있음/없음 4종 미리보기 및 PNG/SVG 다운로드를 지원한다.

연결 지도는 data/connections/{id}.js을 일반 script 태그로 필요할 때 불러온다. 로컬 파일의 JSON fetch에 의존하지 않는다.
HTML 파일을 직접 열거나 정적 HTTP 서버/GitHub Pages 등으로 서비스할 수 있다. 새 API나 외부 지도 SDK는 필요 없다.
SVG는 고정된 공통 투영 좌표를 사용하며, 이름 있는 지도와 없는 지도는 경로를 공유한다.
PNG는 브라우저에서 생성하며, 큰 연결 지도는 최대 변 8192px/약 2400만 화소로 제한한다.

좌표/인접 판정의 기준일과 제약: data/connection-validation.json.
각 지역의 참고 지도 URL: data/connections/{id}.js의 referenceMap.
행정동: 2026-10-01, 법정동: 2023-07-29 좌표에 기존 제작 입력의 최신 명칭 반영.
법정동 단순화 좌표의 미세 틈/겹침은 보존한다. 인접 판정이 체계별로 다른 쌍은 제외한다.
단독 지도 파일은 기존의 2026-09-30 참고 그림 기반 결과를 그대로 사용한다.

재생성 (apt-utils에서 실행, numpy/scipy/Pillow 필요):
python3 blank_map/tools/build_connections.py ../전체지역_백지도/제작자료
입력 파일·기준일을 검토한 후 재생성한다. 실행 시 경계를 자동 갱신하지 않는다.

검사 (apt-utils에서 실행):
node blank_map/tests/connections.test.js
node blank_map/tests/app.test.js
127개 지역 전체의 구역 내부 라벨/인출점, 구멍·분리 구역, 폐합 경로, 동일 벡터,
인접 그래프, 연결 상태/실패/빠른 전환을 검사한다.
실제 브라우저의 폰트와 PNG 내보내기는 별도 브라우저 확인이 필요하다.
