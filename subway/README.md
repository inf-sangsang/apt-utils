# 지하철 이용량 비교

`subway.html`을 열거나 APT Utils 메인의 지하철 이용량 버튼으로 이동한다. 외부 라이브러리와 서버 API 없이 동작한다.

- 원본: STCIS 정류장별 시간대 승하차 자료를 검증한 `outputs/transit_20261031/요일평균_계산자료.json`.
- 원본 레코드는 역·호선 조합 752개. 기본 보기에서는 호선별로 표시한다.
- 호선 태그는 노선별 대표 색상으로 표시한다. 호선 통합에서도 각 호선을 별도 태그로 유지하며 밝은 배경에서는 검정 글자를 사용한다. 색상 대조 자료: https://www.alphawiki.org/raw/틀:수도권_전철_역_목록
- 호선 드롭다운 오른쪽의 스위치로 ‘호선별 분리 / 호선 통합’을 전환한다. 통합하면 이름이 정확히 같은 역의 모든 호선 수치를 더한다. 호선 필터는 해당 호선이 포함된 역을 찾으며 통합 수치는 항상 모든 호선의 합계다. 이미 담은 역에도 적용하고, 분리로 전환하면 원래 담았던 호선 목록으로 돌아간다. 통합 상태에서 새로 담으면 그 역의 모든 호선을 저장하며, 삭제하면 해당 역의 모든 호선을 목록에서 제거한다.
- 07~08시, 08~09시, 17~18시, 18~19시는 월~금 해당 시간대의 일평균.
- 평일 평균과 주말 평균은 각각 월~금, 토·일의 하루 24시간 총이용량 평균.
- 일주일 이용량은 월~일 각 하루의 24시간 총이용량 합계. 전체 요일 일평균과 다르다.
- 모든 항목에 승차·하차를 나란히 표시하며 각각 정렬할 수 있다. 표시할 때 명 단위로 반올림하고 계산에는 반올림 전 값을 사용한다.
- 장암 7호선은 사용자 지정 0. 복정 수인분당선·신내 6호선은 이전 관측일로 빠진 요일을 보완했다. 날짜는 화면 및 배포 데이터에 넣지 않는다.
- 원문 두 블록의 식별이 미확정인 서울 1호선은 제외. 금정 4호선, 김포공항·부천종합운동장 서해선의 미확정 보고서도 추가하지 않는다. 일부 자료를 전체 수도권의 완전한 집계로 간주하지 않는다.
- 선택한 역 ID만 브라우저 localStorage에 저장한다.
- 지역 정보는 실제 STCIS 검색 행을 보존한 `query_mappings.json`의 `sourceRow`(시·도 / 시·군·구 / 동)를 역·호선별로 연결한다. 752개 조합 모두 지역 정보가 존재하는지 생성 시 검사한다. 역명 위에는 시·도와 시·군·구를 회색으로 표시하며, 시·도·시·군·구·동 모두 검색할 수 있다. 호선 통합 시에는 구성 호선의 지역 정보를 중복 제거해 함께 표시·검색한다.

데이터 재생성: 저장소 상위 작업 폴더에서 `python3 apt-utils/subway/build_data.py`. 생성한 `data.js`를 페이지와 함께 배포한다. 날짜별 원자료와 계산 정책은 상위 작업 폴더에 보존한다.
